# OpenCLSim notebooks in GitHub Codespaces

These notebooks can be run directly in GitHub Codespaces.

## Getting started

1. Open the OpenCLSim repository.
2. Create a GitHub Codespace using the OpenCLSim DFSI Environment.
3. Wait until the environment has finished building.
4. Open the `notebooks` folder.
5. Open the notebook you want to run.
6. When asked to select a Python kernel, select:

   **Python (OpenCLSim)**

7. Run the notebook from the beginning using:

   **Run All**

No local Python installation is required.

## Recommended notebook

Start with:

`34_fleet_optimization.ipynb`

## Important

The Codespace is a temporary development environment. Save any files you want to keep by committing them to your own fork or downloading them.
